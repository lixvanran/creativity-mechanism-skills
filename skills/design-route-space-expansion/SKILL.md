# 设计路线 · 搜索空间拓展

> 来自「层 2：运用设计的手段优化搜索空间塌缩」这条研究线的**可执行结论**。
> 研究底稿：`references/`（预注册与判决）、代码在 `scripts/`。

## 什么时候用

| 场景 | 用法 |
|---|---|
| 要 N 个**彼此不同**的方案（不是 N 个说法不同的同一个方案） | 换**认知位置**（frame），不要只换身份标签 |
| 任务"答案唯一但路径可多样" | 目标是**路径多样**，不是答案多样 |
| 任务"推导唯一"（物理定律类） | ★ **别用发散** —— 收敛反而对 |

## 核心结论（★ 窄表述，强度已校准到证据）

> 在【**推导唯一**】的任务上，任何架构旋钮都**无可测贡献**；在【**路径多样**】的任务上，【**交互结构级**】的多样性有大幅效应，而【**prompt 级**】的身份多样性**无效**。
> ⇒ 结论不是「架构没用」，而是「**架构的杠杆是【交互结构 × 任务结构】的交互，且二者必须分开测**」。

★ 实测：跨**型号**、跨**认知框架**、**分支数**三个旋钮在全任务集上**全无可测贡献**（加支数还负向）。⇒ **"换模型"和"多开几支"不是拓宽搜索空间的机制。**

## 怎么用

### 1. 先判任务结构（★ 这一步决定后面一切）

```python
from topics4 import TOPICS        # 任务集（含结构标注）
# 任务结构二元：答案唯一×推导唯一
#   答案唯一 + 路径多样 → 塌缩在"说法"层，应拓路径
#   推导唯一            → 塌缩在"结果"层，发散无用
```

★ **判据**：先看题目**是否允许多条推导路径**。物理定律题只有一条 ⇒ 不要发散。

### 2. 换认知位置（frame），不是换身份

```python
from arm3 import FRAMES, PERSONAS, diverge
# FRAMES   = 认知位置（"从失败案例反推""从约束反推""跨领域类比"…）★ 有效的那一轴
# PERSONAS = 身份标签（"资深专家""跨界研究者"…）★ 实测无效的那一轴
branches = diverge(n=5, workers=1, topic=q)   # 5 条分支，每条一个 frame
```

★ **公平性（关键）**：等预算臂 `B0_bestof3` 的 N 条分支 = **N 次独立直调**；本 skill 的 N 条分支 = **N 个不同认知位置**。⇒ 两者都是"N 条并行分支" ⇒ **路径间多样性直接可比** ⇒ 这才是干净的"搜索空间拓展"证据，而不是"我们调用得多"。

### 3. 用零判官度量（★ 判官读数在原理上看不见这个效应）

```python
from space import space_report
rep = space_report(arm_payload)   # path_diversity / ops_entropy / frame_coverage
```

★ **为什么必须零判官**：实测**判官读数的中位波动 = 1**（即使用最理想的 non-thinking 判官，n=12），而维度数本身只有 1–5 ⇒ ⇒ **任何 ≤1 的架构级效应在原理上就看不见**。⇒ 架构"确实拓展了搜索空间"这件事，**不能靠判官读数证明**。

| 指标 | 定义 | 对应目标 |
|---|---|---|
| `path_diversity` | N 条并行分支**彼此**的 Self-Sim（越低越分散） | 搜索空间拓展能力 |
| `ops_entropy` | 单条路径的**操作序列 n-gram 熵**（归一化） | 思维跳跃程度 |
| `frame_coverage` | 用了几种不同的认知位置 | 拓展来源是否多样 |

### 4. 失败支必须显式记账（★ 血泪纪律）

```python
from dual import Dual
r = Dual("select").run(llm, topic, rep)
r.notes["n_specs"]      # 计划支数
r.notes["models_used"]  # 实际用到的型号
r.notes["models_failed"]# ★ 失败的支必须在这里，不能静默消失
```

★ **旧实现 `return [o for o in outs if o]` 会把失败支静默少算一支 ⇒ 5 支静默变 4 支，表上看不出来。** ⇒ **跑批时型号池里可能有型号已下架** ⇒ 任何"用满 N 支"的场合，**先核支数是否真为 N**。

## 硬纪律

1. ★ **任务结构与交互结构必须分开测** —— 混在一起就分不清是哪个在起作用。
2. ★ **主判据用零判官度量**；判官读数只作辅助。
3. ★ **失败显式记账**；分母写「有效(原始)」双写。
4. ★ **报"不可分辨"必须同时报检出力地板**；**不可分辨 ≠ 无效应**。
5. ★ **"架构没用"不是本 skill 的结论** —— 结论是"杠杆是【交互结构 × 任务结构】的交互"。
