## 0. 阅读须知：本报告的立场

这份报告**不是**「把 ADHD 的优点移植到 Agent 上」的方案书。动笔前有三条硬前提必须摆在最前面，否则后面的内容会被误读。

**前提一：作为类比基础的命题，本身没通过证据审计。**

我们对「ADHD ⟶ 更高创造力」做了对抗性审计，裁决结果：

| 子命题 | 裁决 | 置信度 |
|---|---|---|
| ADHD 人群现实创造力产出整体更高 | **反对** | 高 |
| 控制混杂后效应仍成立 | **反对 / 未找到支持** | 高 |
| 认知代价抵消创造力收益 | **支持** | 高 |
| 线性正相关（限临床区间） | 反对 | 中高 |
| 亚临床区间线性正相关 | 部分支持 | 中高 |
| 发散思维测验分数更高 | 证据不足（偏向微弱支持） | 低 |

唯一的大规模元分析（89 项研究、N=35,271）给出 **r = −.06，95% CI [−.15, .02]，区间跨 0**，且其自带发表偏倚检验为阳性。

**前提二：可以取的是「功能目标」，不是「实现方式」。**

几乎每个 ADHD 特质都能拆成两层：

```
功能目标：这个机制想达成什么认知效果   ← Agent 能取
实现方式：靠什么生物硬件实现           ← Agent 拿不了（没有大脑、没有多巴胺、没有睡眠）
```

本报告所有条目都只取第一层。

**前提三：下面带「实测」标签的数字，来自我们自己的实验；带文献标签的来自第三方。两者不混。**

**我们的实验条件**（必须一起读，否则数字会被误用）：
- 模型：MiniMax-M3，**温度全程锁死 1.0**，门控是唯一自变量
- 规模：72 个 (任务, 种子) 配对单元 × 4 臂 = 288 次单元级观测，1,728 次 API 调用
- 效用：**零 LLM 裁判**，三个确定性判定器（单元测试通过率 / 硬约束满足率 / 远-用几何均值）
- 新颖性：TF-IDF 余弦距离 + 字符 4-gram Jaccard，双指标交叉验证

## 2. 逐条详解

### 特质 1 · 远联想（Associative Hierarchy / Mednick）

**特质是什么**
创造力的经典定义（Mednick 1962）：把联想元素组合成新的搭配，**元素之间越是相互遥远（mutually remote），过程就越有创造力**。

⚠️ 一个必须保留的细节：原文还有**并列的第二个判据**——"which either meet specific requirements or is in some way useful"。**「远」与「有用」是并列条件，不是二选一。** 只实现前者，优化目标就会退化成「越怪异越好」。

**ADHD 侧证据**：中低。机制本体（Benedek & Neubauer 2013，*J Creat Behav* 47(4):273–289）被直接检验**未获支持**——高低创造力者的联想层级并无差异，差别在联想流畅度与非常规回答数量。

**可取的功能目标**：提高候选之间的语义距离，同时保留可用性。

**Agent 层实现**

```python
def generate_gate(prompt, K=8, budget=16, tau=0.90):
    """生成门：批内语义去重。只放宽多样性，不管质量。"""
    cands = sample(prompt, n=budget, temperature=1.0)   # 温度必须锁定
    accepted = []
    for c in cands:
        if len(accepted) >= K: break
        if accepted and max(semantic_sim(c, a) for a in accepted) > tau:
            continue                                    # 与已接受者太像 → 丢弃
        accepted.append(c)
    return accepted or cands[:K]
```

**实测结果**：单用此门 → 新颖 **+8.3%**（p=0.005），效用 **+3.4%（p=0.546，不显著）**。

**这条实测的解释**：生成门**只买新颖，不买效用**。它是纯探索。

**风险**：成本翻倍（本实现中 2.00× API 调用）；且若 τ 取得过松，批内质量会塌。

**文献印证**：SemDiD（NeurIPS 2025, arXiv 2506.23601）做的是同一件事的解码层版本——它指出温度和 diverse beam search 只产生**词汇多样性**，「底层逻辑一样」，管这叫 semantic redundancy。SemDiD 报告 Best-of-N 覆盖率提升 1.4%–5.2%（**该数字未核原文**）。

**判定**：✅ 可迁移。有实测、有文献、机制清楚。

### 特质 2 · 发散↑ / 收敛↓ 的失衡 ⭐ 本报告最有价值的一条

**特质是什么**
这是 ADHD 研究里最稳定的**解离现象**：发散思维随症状升高，但到了临床区间就平台化；**收敛思维不升反降**；工作记忆、规则遵守、自评能力普遍更差。

**这不是一个「优势」，是一个失衡。**

**ADHD 侧证据**：高。Stolte et al. 2022（n=470 一般人群 + n=151 ADHD）测到发散上升但无收敛增益；Fang et al.（n=1,170 双生子，控制 IQ）发现注意力维度与产品型创造力**负相关**。

**可取的功能目标**：**探索与利用的失衡是需要被显式管理的设计参数。**

**Agent 层实现**

```python
def select_gate(pool, scorer, theta=0.60):
    """选择门：先过效用门，过门者中选离质心最远者。
       这是四个臂里最大的单一收益来源。"""
    scored = [scorer(c) for c in pool]
    passed = [i for i, s in enumerate(scored) if s >= theta]
    if passed:
        return pool[min(passed, key=lambda i: dist_to_centroid(pool[i]))]
    # 无人过门：退化为「取效用最高者中离质心最近的」（保守）
    best = max(scored)
    cands = [i for i, s in enumerate(scored) if s >= best - 1e-9]
    return pool[min(cands, key=lambda i: dist_to_centroid(pool[i]))]
```

**实测结果**：单用此门 → 效用 **+12.3%**（p=0.003），新颖 **−2.3%**（p=0.004，**下降**）。

**这条实测的解释**：选择门**只买效用，不买新颖**。它是纯利用。

**⚠️ 但这不是缺点，而是这份报告最反直觉的发现：**

| 臂 | Δ效用 | Δ新颖 | 解耦比 |
|---|---|---|---|
| 只收紧生成门 | +3.4% | +8.3% | 2.45 |
| **全链路发散→收敛** | **+14.5%** | **+6.8%** | **0.47** |

「+78.8% 多样性 / +13.9% 整体」那个代价模式，**只出现在「只放开生成、不管选择」时**。加上选择门，效用涨得比新颖快，**权衡被翻转**。

也就是说：**ADHD 的「发散↑收敛↓」这个失衡，在 Agent 上的正确解法不是学它，而是补上它缺的那一半。**

**文献印证**：多智能体领域独立得到同向结论——**选择优于综合**。负责挑选最佳单答案的编排器，稳定优于把多答案融合成新答案的编排者（**该条来自二手综述，原始论文未定位，是本报告最需独立验证的一根柱子**）。

**判定**：✅ 可迁移，本报告最推荐。

### 特质 3 · 即时奖励偏好（时间贴现）

**特质是什么**
ADHD 个体对延迟奖励的折现率显著更高——他们要「现在」，不要「以后」。Wilson et al. 2011 测到 ADHD 组贴现更陡，但**这个效应在控制 IQ 后不存活**。

**ADHD 侧证据**：中，且对 IQ 敏感。

**可取的功能目标**：**对新颖的偏好可以被显式加权，而不必依赖模型自己「偏爱新奇」。**

**Agent 层实现**

```python
def weighted_tail_sampling(prompt, k=5, tau=0.10):
    """把「要新奇」变成显式权重，而不是靠模型自发偏好。"""
    resp = ask(prompt + f"\n生成 {k} 个答案，每个都给出你估计的概率。")
    items = parse(resp)                     # [(text, prob), ...]
    items = [it for it in items if it.prob >= tau]   # 丢弃典型答案
    return rng.choices(items, weights=[i.prob for i in items])[0]
```

**文献依据**：Verbalized Sampling（arXiv 2510.01171, ICML 2026）——创意写作多样性 **1.6–2.1×**，恢复基础模型多样性的 **66.8%**，事实性与安全性无明显损失。这三个数字已抓 arXiv v4 全文 HTML 逐字核对。

**VS 论文揭示的底层机制值得单独记**：它证明人类标注者在偏好数据里有**典型性偏误**——偏好「更典型」文本的比例 **51.6%–60.8%**（已核原文）。推论很硬：**即使奖励模型完美，数据带这个偏误，坍塌照样发生。**

**开源实现**：`CHATS-lab/verbalized-sampling`（★812，2026-01-03），核心就一行 `selection.py:149` 的 `rng.choices(..., weights=self.p)`。

**风险**：需要模型能可靠地自报概率；小模型上概率估计不可靠。

**判定**：✅ 可迁移。有强文献、有可用实现、零训练成本。

### 特质 4 · 心智游移 / 默认模式网络活跃

**特质是什么**
ADHD 的思维漂移、解离状态，被普遍认为可能促进远联想与 incubation。

**ADHD 侧证据**：低-中。Lacaux et al. 2021（N=103）测到长 N1 睡眠窗口下解离任务表现 83% vs 30%；Baird et al. 2012 测到「低要求的干扰任务」有益于酝酿。**但这些样本大多不是 ADHD 被试**——把它们当 ADHD 机制证据是被我们的审计明确点出的错误。

**可取的功能目标**：**「不要一次给出唯一答案，而是保留并利用之前的答案。**

**Agent 层实现**

```python
def in_context_regeneration(prompt, previous_answers):
    """不假装「重新想」，而是显式把旧答案放进上下文要求不同。
       NoveltyBench 实测此法可达人类多样性水平。"""
    ctx = "\n\n".join(f"你之前的回答{i+1}：{a}" for i, a in enumerate(previous_answers))
    return ask(f"{prompt}\n\n以下是你已经给过的答案：\n{ctx}\n"
               f"给出一个与上述所有答案**在功能上不等价**的新答案。")
```

**关键点**：这不是「模拟走神」。是**把已生成的候选保留在上下文里**作为负例——LLM 是无状态的，「忘掉刚才说过什么」只能靠显式重述来实现。

**文献依据**：NoveltyBench（COLM 2025, arXiv 2504.05228）实测 in-context regeneration 可显著提升多样性、达到人类水平（同组作者的表述）。

**判定**：✅ 可迁移，但**是「生成门」的变体，不是独立机制**。

### 特质 5 · 失败—重试循环（failure-retry loop）

**特质是什么**
Eysenck 的假说：低表现 → 降低内在动机 → 转而投入创造性活动。

**ADHD 侧证据**：**未找到原始出处。** 审计明确标注 Europe PMC `AUTH:"Eysenck HJ" AND creativity` 仅 2 命中，均非 1993/1983 原文。

**可取的功能目标**：**低产出的中间步骤应触发策略切换，而不是重试同一路径。**

**Agent 层实现**

```python
def verify_and_retry(task, max_rounds=3):
    """验证器在环。注意：重试必须换路径，不是换随机种子。"""
    for r in range(max_rounds):
        out = generate(task, strategy=STRATEGIES[r])   # 策略必须不同
        score = verifier(out)                          # 确定性验证器，不是 LLM 自评
        if score >= THETA:
            return out, score
        task = add_failure_context(task, out, score)   # 把失败写进上下文
    return best_of(pool), max_score
```

**⚠️ 这里有一条我们实验里被证实的危险**：**不要用 LLM 自我打分选最优。** 已知自评者与生成者同分布，**自评天然偏好训练分布中心附近的输出，也就是最平庸的候选**。必须用外部可验证约束（编译通过、单元测试、形式化规格）。

**文献依据**：本次未实测。相关证据来自 Tree-of-Thought（NeurIPS 2023, ★6077）——自评估 + 前瞻 + 回溯三件套；以及「基伍德原则」的普遍报道。

**判定**：✅ 可迁移，但**证据等级中等，且本次未做实验验证**。是清单里唯一「看起来合理但我没测过」的条目。

### 特质 6 · Hyperfocus / 心流

**特质是什么**
极端专注状态与「分心」看似矛盾，但对创造力的作用是正面的。

**ADHD 侧证据**：低且**多为阴性**。Groen et al. 2020（n=1124+78）与 Dupuis et al. 2022（n=5744）测到 hyperfocus **并非 ADHD 特异**，ASD 被试表现相当或更强。

**可取的功能目标**：**在长时间单一目标上维持高强度投入。**

**Agent 层实现**：长程推理结构（Tree-of-Thought / 分支回溯）。但必须诚实说明：**这是工程类比，不是机制迁移。** Agent 没有注意力资源可耗尽，也没有 flow 状态。

**判定**：⚠️ 间接可迁移。工程收益确定（ToT 有大量复现），但把它叫作「hyperfocus 的实现」是过度解读。

### 特质 7 · 新颖寻求 / 感觉寻求

**特质是什么**
ADHD 人群对新奇刺激的偏好更强，导致候选池更宽。

**ADHD 侧证据**：低。Plichta & Scheres 2014 测到纹状体多巴胺反应低（d=0.48–0.58），但**神经影像层面的差异不等于创造力优势**——我们的审计把这叫「拆开」：神经影像 A 级证据 ≠ 创造力收益。

**Agent 层实现**：采样参数（temperature / top-p）。

**⚠️ 这是清单里收益最小的一条，而且是明确应当废弃的：**

> DIVERGE（arXiv 2602.00238）指出：温度类方法**在输出分布已坍塌时改善有限**；而且 **GPT-5、o3 这类前沿模型已经不再暴露解码控制参数**。

加上我们实验里的温度锁定设计——全程锁死 1.0，仅靠门控就拿到两轴同向改善——这条已经没有任何理由作为主要手段。

**判定**：⚠️ 可迁移但**建议不用**。这不是「有效但次优」，是「在 2026 年已失效」。

### 特质 8 · 睡眠 / 入睡期意象（incubation） ❌ 危险区

**特质是什么**
「睡一觉答案就出来了」。Wagner et al. 2004 *Nature* 报告：睡后获得隐藏规则洞察的人数是清醒时的两倍以上，且前兆是**跨睡眠的反应时减慢**。Lacaux 2021 测到长 N1 窗口下 83% vs 30%。

**ADHD 侧证据**：**这恰恰是最不 ADHD 特异的机制。**「创造性出现在失能状态」是所有人的现象，只是触发方式不同。

**Agent 层实现**：**没有。**

**为什么不可迁移**：LLM 是**无状态的**。加一个 `sleep(N)` 不改变任何条件分布——它只是等了几秒。这是整份清单里最容易被误实现的一条。

**危险区警示**：任何声称「给 Agent 加个『想一想』的停顿能提升创造力」的说法，在无状态 LLM 上都不成立。**停顿 ≠ 酝酿。**

**判定**：❌ **不可迁移，且列为最高优先级禁令。**

---

## 3. 明确不可迁移的清单（不许偷偷绕过去）

| 项 | 为什么搬不过来 |
|---|---|
| **睡眠 / 意识状态切换** | Agent 无状态，无意识状态可切换 |
| **内在动机的自我补偿** | Agent 没有内在动机，也没有需要补偿的东西 |
| **神经可塑性** | 训练侧概念，不是推理侧设计参数 |
| **临床人群的伦理负担** | 诊断标签会直接转移到用户身上——把「ADHD 式 Agent」卖给用户，等于把一个临床构型当卖点 |
| **失败-重试中对失败的容错** | Agent 没有「人生」可失败，不存在需要逃避的失败 |
| **药物调节的多巴胺通路** | 没有硬件可调 |

## 4. 禁令（照搬就会降低质量）

1. **❌ 不要用 `sleep(N)` 模拟酝酿。** 无状态 LLM 上它不改变任何条件分布。
2. **❌ 不要用 LLM 自我打分选最优。** 自评者与生成者同分布 → 自评天然偏好最平庸的候选。
3. **❌ 不要只优化「远」而不设「有用」的约束。** Mednick 的两个判据是并列的。实测证据：最佳臂把「远」拉高 16.7 个百分点，而「用」只动了 0.25 个百分点——**这不是解耦，这是用性没跟上。**
4. **❌ 不要把「提高温度」当作创造力方案。** 前沿模型已不暴露该参数；分布已坍塌时它也无效。
5. **❌ 不要用「新颖—有用」的对称几何均值做产品指标。** 应引入可调的耐心参数 γ（见下）。
6. **❌ 不要把多候选聚合（MoA 类）当作多样性方法。** 聚合本身会消除多样性。`togethercomputer/MoA` 全仓 grep 不到任何 diversity 度量代码。
7. **❌ 不要相信词汇级多样性指标。** 我们实测：两个指标族内 ρ=0.77/0.78 但**合并仅 ρ=0.135**——跨任务族不可比。改写会被误判为多样。

## 5. 如果真的要落地：推荐配置

```python
def creative_agent_solve(task, K=8, budget=16, tau=0.90, theta=0.60):
    # 温度锁死，不作为旋钮
    pool = generate_gate(task, K, budget, tau)          # 探索：语义去重
    winner = select_gate(pool, deterministic_scorer, theta)  # 利用：效用门 + 选最异
    return winner
```

**配置说明**

| 参数 | 建议起点 | 说明 |
|---|---|---|
| `temperature` | **锁定** | 不作为创造力旋钮 |
| `K` / `budget` | 8 / 16 | 成本 2.00× |
| `tau` | 0.90 | 太松会塌批内质量 |
| `theta` | 按任务类型调 | **不要固定** |
| `scorer` | **必须是确定性判定器** | 绝不用 LLM 裁判 |

**按任务类型调 θ**（依据 Homogenization Taxonomy, arXiv 2509.21267）：单一正确答案类任务 θ 应高（0.9+）；创意写作类 θ 可低（0.5–0.6）。**同质化在某些任务里是好事。**

**分族实测结果**（必须分族读，合并层的新颖性不可信）：

| 族 | 全链路发散→收敛的 Δ效用 | p | Δ新颖 | p |
|---|---|---|---|---|
| CODE | +25.5% | 0.060 | +7.1% | 0.080 |
| CONSTRAIN | +5.4% | 0.509 | +11.6% | 0.081 |
| REMOTE | **+15.2%** | **0.025** | +0.3% | 0.878 |

**诚实读法**：**效用三族全为正（两族显著），新颖性只在两族成立且边缘显著，REMOTE 族完全没有。**

→ 「两轴同向大幅改善」这个说法，**数据不支持**。能说的是：效用稳健可买，新颖性部分可买。

## 6. 本报告的局限

1. **所有「可迁移」判定都是设计假设，不是已验证方案。** 我们只做了一个模型、一个温度、12 个任务、每任务 6 个种子。
2. **新颖性度量是词汇级的**（TF-IDF + 字符 n-gram），沙箱无 embedding 模型。REMOTE 族族内 ρ 仅 0.275，该族新颖性结论尤其脆弱。**「选择优于综合」那条文献支撑来自二手综述，原始论文未定位。**
3. **效用是我的规则定义，不是人的判断。** 无 LLM 裁判是刻意的（裁判一致性仅 ~50%），代价是这里测的是「满足我写的约束」。
4. **「远联想」被（Benedek & Neubauer 2013）直接检验为 null。** 我仍保留它作为功能目标，理由是它作为**工程启发**仍然有效（实测支持），而非因为它在 ADHD 上被证实。
5. **未测特质 5（失败—重试循环）与特质 6（hyperfocus）**，清单里这两条是推理而非实测。
6. **不涉及训练侧方法**（DivPO、Darling、MUPO 等）。本报告全部限定在推理时。

## 附录：一句话总结

> **不要做「ADHD 化的 Agent」。**
> 要做的是：取走「探索与利用失衡」这个**观察**，然后用两道门把失衡补回来——
> **生成门只管探索，选择门只管利用。**
> ADHD 提供的是问题描述，不是解决方案。实测已经证明：加满选择门，权衡会翻转成有利方向。
